## 3. Final system (verified against checkpoints and inference code)

**C1 × 3** = three full-data models with identical recipes and seeds 1, 2, 3:
- `checkpoints/v5_ecapa_concat/full_data` (seed 1);
- `checkpoints/v6_ecapa_concat_ens/seed_{2,3}/full_data`.

| Stage | Verified detail |
|---|---|
| Face encoder (frozen) | FaRL ViT-B/16 `FaRL-Base-Patch16-LAIONFace20M-ep16` (sha256 `67b4d6bc…`), CLIP preprocessing, 224 px, no alignment, L2-normalised **512-d** |
| Voice encoder 1 (frozen) | WavLM Base+ (`microsoft/wavlm-base-plus-sv` @ `feb593a6`), 16 kHz, 10 s chunks / 5 s overlap, frame mean of all 13 hidden states averaged over layers: **768-d** |
| Voice features 2 | eGeMAPS v02 functionals (openSMILE 2.5.1): **88-d**, median-imputed and clipped to training percentiles |
| Voice encoder 3 (frozen) | ECAPA-TDNN `yangwang825/ecapa-tdnn-vox2` @ `c605f571`, whole clip: **192-d** |
| Voice input | concatenation 768 \| 88 \| 192 = **1,048-d** |
| Projector (both branches) | z-score (stored training mean/std) → [train only: Gaussian noise σ = 0.1, input dropout 0.2] → Linear → **256** → LayerNorm → GELU → Dropout 0.3 → Linear → **128** → L2 normalisation |
| Parameters per model | face 164,736 + voice 301,952 = 466,688 (+ an unused 301 × 128 ArcFace classifier kept for checkpoint compatibility); training-only trait and language heads in `aux_state_dict` |
| Training | 301 identities (70 official + 231 external), 36,187 rows; symmetric SupCon (τ = 0.07) + 0.25 pair alignment + 0.2 shared trait heads + 0.1 language adversary (GRL) + 0.1 cross-lingual alignment; AdamW lr 1e-4, wd 1e-4, clip 5; P16 × K8, 50% official identities, 50 batches/epoch, 90 epochs |
| Per-model score | d_k = 1 − cos(face_k, voice_k) |
| Ensemble | d = (d₁ + d₂ + d₃) / 3 (equal weights; no score statistics) |
| Fixed terms | d += w_age · \|ĉ(voice age) − face age\| / 10 + w_gender · \|p_male(voice) − male(face)\|; voice age and p_male from audeering wav2vec2 age/gender, linearly corrected per predicted gender (fitted on official training rows); face age and gender from InsightFace `buffalo_l`; weights standard 0.02 / 0.05, gender track 0.02 / 0 |
| Output | distance per trial (lower = more likely the same person); every trial scored from its own face and voice only |
